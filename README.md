# Travel Package Builder
This is a simple Java project that shows how the Builder Patterns work.
The program creates two types of travel packages:
- Budget Travel
- Luxury Travel

## Classes

- TravelPackage - stores travel information
- TravelPackageBuilder - builder interface
- BudgetTravelBuilder - creates a budget trip
- LuxuryTravelBuilder - creates a luxury trip
- TravelDirector - creates ready trip options
- Main - runs the program

## How to Run
1. Open the project in IntelliJ IDEA
2. Use JDK 17
3. Open Main.java
4. Run the program

This program will print budget and luxury travel packages
